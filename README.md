# YouTube Comment Sentiment Detection

A Flask-based machine learning API paired with a Chrome extension that analyzes YouTube video comments. The extension fetches comments, sends them to the API for sentiment inference, and renders summary metrics plus visualizations (pie chart, trend graph, and word cloud).

## Key Features

- **Sentiment analysis** of YouTube comments using a trained LightGBM model and TF-IDF vectorizer.
- **Chrome extension UI** that shows summary metrics and top comments with predicted sentiment.
- **Visual analytics** generated by the API: sentiment distribution pie chart, trend graph over time, and a comment word cloud.
- **Local development workflow** with a Flask API and DVC for reproducible ML assets.

## Prerequisites

- **Python 3.9+**
- **pip**
- **DVC** (for reproducing the ML pipeline)
- **Google Chrome** (for the extension)
- **YouTube Data API key** (for the extension to fetch comments)

## Setup

### 1) Create and activate a virtual environment

**Windows (PowerShell / CMD)**
```bash
python -m venv env
env\Scripts\activate
```

**macOS / Linux (bash / zsh)**
```bash
python3 -m venv env
source env/bin/activate
```

### 2) Install dependencies

```bash
pip install -r requirements.txt
```

### 3) (Optional) Reproduce the ML pipeline with DVC

If you want to rebuild the model artifacts:
```bash
dvc init
dvc repro
```

## Running the API

From the project root:
```bash
python flask_api/main.py
```

The API will start on `http://localhost:5000`.

## Chrome Extension Installation

1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode**.
3. Click **Load unpacked** and select the `yt-chrome-plugin-frontend` folder.
4. In `yt-chrome-plugin-frontend/popup.js`, set your **YouTube Data API key**:
   ```js
   const API_KEY = 'use_your_actual_api';
   ```
5. Ensure the API URL is correct (default: `http://localhost:5000/`).

## Using the Extension

1. Open a YouTube video.
2. Click the extension icon.
3. The extension will fetch comments, call the API for predictions, and render:
   - Comment analysis summary (totals, unique commenters, average length, sentiment score)
   - Sentiment distribution pie chart
   - Sentiment trend over time
   - Word cloud
   - Top comments with sentiment labels

## API Endpoints

Base URL: `http://localhost:5000`

| Method | Endpoint | Description |
| --- | --- | --- |
| POST | `/predict` | Predicts sentiment for a list of comments |
| POST | `/predict_with_timestamps` | Predicts sentiment for comments with timestamps |
| POST | `/generate_chart` | Returns sentiment distribution pie chart image |
| POST | `/generate_trend_graph` | Returns sentiment trend graph image |
| POST | `/generate_wordcloud` | Returns a word cloud image |

### Example: Predict sentiment

```bash
curl -X POST http://localhost:5000/predict \
  -H "Content-Type: application/json" \
  -d '{"comments": ["Great video!", "This was terrible."]}'
```

### Example: Predict with timestamps

```bash
curl -X POST http://localhost:5000/predict_with_timestamps \
  -H "Content-Type: application/json" \
  -d '{"comments": [{"text": "Nice!", "timestamp": "2024-01-01T10:00:00Z"}]}'
```

## Troubleshooting

- **No comments returned**: ensure the YouTube Data API key is valid and has access to the YouTube Data API v3.
- **CORS errors**: confirm the Flask API is running and the extension is pointing to the correct `API_URL`.
- **Model/vectorizer missing**: run `dvc repro` (if artifacts are DVC-managed) or verify the `.pkl` files exist next to `flask_api/main.py`.
